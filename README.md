# kobaesystem

台所の洗い物放置・キッチン/浴室の排水溝放置による、菌の増殖リスクとコバエ発生リスクを可視化するシミュレーターです。

## 使い方

このツールはサーバー不要の単一HTMLファイルです。リポジトリをclone（またはpull）したあと、`kitchen-hazard-monitor.html` をブラウザでダブルクリックして開くだけで動作します。

- 洗い物タブ：放置時間・室温・湿度・汚れの種類から、菌の増殖倍率とコバエ発生リスクを推定
- キッチン排水溝タブ：清掃からの経過日数・使用頻度・室温から、ヌメリ蓄積とコバエ発生リスクを推定
- 浴室排水溝タブ：清掃からの経過日数・使用頻度・浴室の湿度から、同様のリスクを推定
- 画面上部のバナーに、3つのリスク源を合成した総合コバエ発生リスクを表示

推定値はいずれも簡易モデルによる概算で、教育・啓発目的のツールです。
