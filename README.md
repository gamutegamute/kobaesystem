# ぬりかえす (nurikaesu_ink)

洗い場の放置時間を「インク」のメタファーで可視化する、ゲーム型サイネージのプロトタイプです。画面には温湿度とキャラクターが表示されていますが、放置時間が長くなるほどマス目状のインクが少しずつ画面を覆っていき、やがて情報が完全に見えなくなります。指で画面を横方向になぞる「ワイパー」操作でインクを拭き取ると、情報が見えるようになると同時に放置タイマーがリセットされます。

## 対象ハードウェア

- M5Stack Core2
- ENV III ユニット(SHT30, Port A: G32=SDA / G33=SCL)

## 必要ライブラリ

Arduino IDE のライブラリマネージャからインストールしてください。

- M5Unified
- M5GFX(M5Unified に同梱)

SHT30(ENV III)は外部ライブラリに頼らず、`Wire` で直接 I2C を叩いて読み出しています。

## 主な仕組み

- 画面をマス目(12×16)に分割し、マスが「出現する順番」だけをあらかじめシャッフルしてある。これにより塗り面積(占有率)が放置時間にほぼ比例する
- 掃除の操作は横方向のワイパー。指を左右にスライドさせると、その位置を中心に縦1列分(画面の上から下まで)がインクごと拭き取られる。汚れているマスの80%(既定値)を拭き終えると「掃除完了」と認定され、放置タイマーがリセットされる
- 拭きかけの状態で一定時間(既定1.2秒)操作をやめると、拭きかけの範囲は汚れに戻る(=覗き見だけでは掃除したことにならない)

## 開発用の設定

`nurikaesu_ink.ino` 冒頭の定数で調整できます。

| 定数 | 説明 |
| --- | --- |
| `DEV_SPEED_MULTIPLIER` | インクの変化速度の倍率。開発中の動作確認用に上げておき、本番では `1.0f` に戻す |
| `WIPE_COMPLETE_RATIO` | 掃除完了と認定する拭き取り割合(既定 0.80) |
| `WIPE_IDLE_RESET_MS` | 拭きかけの範囲が汚れに戻るまでのアイドル時間(ms) |
| `SHOW_DEBUG_HUD` | 開発用デバッグ表示(占有率・拭き取り進捗など)の表示切替 |

## 今後の展望

- `drawCharacter()` は仮の丸顔を描画しているだけなので、`pushImage()` で実際のイラスト/スプライトに差し替え可能
- 温湿度・キャラクターの表示位置とサイズは画面の高さから比率で自動計算しているため、解像度が異なる機種でも大きく崩れない設計にしている
